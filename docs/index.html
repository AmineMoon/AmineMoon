About

This is a simple, dependency-free Snake game implemented for GitHub Pages. I added touch controls and on-screen buttons so visitors can play on mobile.

How to enable Pages

  1. Go to your repository Settings > Pages
  2. Set Source to Branch: main and Folder: /docs
  3. Save — your game will be available at https://aminemoon.github.io/AmineMoon/ (or similar)

If you want a different Buy Me a Coffee URL, tell me and I'll update the link.
